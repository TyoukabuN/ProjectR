## 1. 游戏定位

Far Far West（遥遥西土）是一款**多人合作 PvE 射击游戏**，融合 Roguelike 式的局内 Build 要素和持久的局外成长系统。玩家扮演西部赏金猎人，组队完成任务、击败 Boss、收集战利品并撤离。

核心循环：
```
大厅准备 → 选择任务 → 局内战斗/Build → 击败 Boss → 撤离 → 局外升级 → 重复
```

---

## 2. 大厅系统（The Saloon）

大厅是玩家组队、整备和社交的核心枢纽，包含多个功能区域：

| 区域 | 功能 |
|------|------|
| **The Gunsmith（枪匠铺）** | 购买、装备、定制武器和工具；用碎片解锁新装备；升级武器基础属性；装备 Weapon Jokers |
| **DR. Spark-Twist's Lab（实验室）** | 获取 Hero Jokers（提升角色属性如生命值、跳跃高度）；购买和装备角色 Joker |
| **The Spell Hut（法术小屋）** | 更换已装备法术；追踪法术解锁进度 |
| **The Rootin' Tootin' Shack** | 购买外观：英雄皮肤、坐骑皮肤、表情（无属性加成） |
| **The Gramophone（留声机）** | 收集 Disc Fragments 组装唱片，改变大厅音乐 |
| **The Shooting Range（射击场）** | 免费测试武器和法术，实验 Build |
| **The Code Whisperer** | 输入官方 Discord 发放的兑换码获取奖励 |
| **The Bestiary（图鉴）** | 近距离查看敌人，追踪击杀数量 |

## 3. 核心局内循环

### 3.1 任务结构

每个任务由三个部分组成：

1. **主要目标（Main Objective）**：完成特定任务目标（如护送、保护、制造炸弹等）
2. **悬赏 Boss（Bounty Boss）**：完成主要目标后召唤并击败 Boss
3. **地图（Map）**：任务发生场景，有固定布局 + 随机生成要素

### 3.2 局内成长

- **Jokers**：局内随机掉落，提供被动效果（类似 Balatro 的 Joker 概念但应用于射击游戏）
- **Souls**：局内货币，可在 Slot Machine 花费 250 souls 随机获取 Joker
- **Gold**：局内货币，用于购买装备和 Joker

## 4. 升级与转生系统

### 4.1 三类等级

| 类型 | 升级方式 | 解锁内容 |
|------|----------|----------|
| **猎人等级（Hunter）** | 游戏过程中积累经验 | 更多升级点数、Joker 槽位 |
| **装备等级（Equipment）** | 用该装备造成伤害 | 更多升级点数、Joker 槽位 |
| **法术等级（Spell）** | 使用该法术 | 解锁新法术 |

### 4.2 转生（Prestige）

- 达到 100 级后可转生
- **效果**：等级重置为 1、出售所有升级、卸下已装备 Joker 到库存
- **奖励**：获得 Token，用于解锁额外的 Joker 槽位和升级槽位，或购买资源（金币、灵魂、票券、碎片）

## 5. 货币系统

| 货币 | 用途 | 获取方式 |
|------|------|----------|
| **Gold** | 购买装备、Joker | 局内掉落、局外奖励 |
| **Souls** | Slot Machine 抽 Joker | 局内掉落 |
| **Fragments** | 解锁新装备 | 局内追踪特定装备后掉落 |
| **Tokens** | 转生后解锁槽位和购买资源 | 转生奖励 |

## 6. 设计启示

### 6.1 值得借鉴的设计

1. **大厅即功能菜单**：将传统 UI 菜单转化为可探索的 3D 空间，增强沉浸感
2. **三类并行的成长线**：角色 + 装备 + 法术，每条线都有独立的升级和转生，提供持久的养成目标
3. **局内随机 Build + 局外固定 Build**：
   - 局内：随机掉落的 Jokers 创造每局不同的体验
   - 局外：可定制的 Weapon Jokers 和 Hero Jokers 提供策略深度
4. **任务目标的玩法多样性**：7 种主要目标不仅是"杀光敌人"，而是包含解谜、护送、记忆等机制
5. **元素交互系统**：三元素（火/电/酸）状态效果 + 法术组合反应，鼓励团队配合和 Build 构建

### 6.2 需要注意的问题

1. **新玩家门槛**：装备解锁需要"追踪碎片"机制，可能需要引导避免玩家不知道如何选择追踪目标
2. **内容深度**：目前 Wiki 显示许多页面仍是 Stub，说明游戏内容可能还在早期阶段
3. **Unique Joker 绑定武器**：强绑定可能造成某些武器过强或过弱，需要平衡
