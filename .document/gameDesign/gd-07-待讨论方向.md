# 七、待讨论与待明确方向

---

## 当前急需讨论

- [ ] 【卡牌】基础规格如何统一？需要明确费用、类型、tag、目标、范围、结算时机、进入【弃牌堆】规则、升级版本与牌面文案模板。
- [ ] 【魔法卡】与【强化牌】的组合关系如何定稿？【语言卡】是作为附带强化使用，还是作为本【回合】变体触发卡使用？
- [ ] 【牌库】循环规则如何定稿？需要明确初始牌库规模、每【回合】抽牌数、【手牌】上限、【抽牌堆】洗牌规则、回合结束未使用【手牌】处理方式。
- [ ] 【弃牌机会】在核心循环中的定位是什么？它是单纯换牌次数，还是玩家主动凑齐【法式】的关键资源？
- [ ] 【卡牌词条】规则需要统一，尤其是【保留】、【回收】、【蒸发】、【消灭】的触发时机与去向。
- [ ] 战后构筑成长如何实现？需要明确战斗奖励、选牌、删牌、升级、卡池解锁与局内成长节奏。
- [ ] 【法式图鉴】如何参与构筑成长？发现【法式】后是只记录，还是会解锁提示、奖励、升级或新【卡牌】？
- [ ] 敌方是否完整使用 DBG 规则？需要明确敌方【卡组】、【手牌】、【魔力值】、【自然回复量】与【行为牌】生成方式。
- [ ] 敌方【行为牌】如何公开与结算？需要明确每【回合】亮牌数量、亮牌来源、是否受敌方【单位】产出影响、玩家可如何干扰。
- [ ] 【混乱度】是否保留？若保留，它应改为敌方压力预算、敌方场上规模指标，还是从规则中移除？
- [ ] 单场战斗胜负目标如何定义？需要明确【城防战】的胜利条件、失败条件、主要保护目标与副目标奖励。

## 后续待讨论

- [ ] 游戏是否包含 Roguelike 元素（每局随机【牌库】/关卡随机化）？
- [ ] 多路线关卡还是线性叙事关卡？
- [ ] 是否有多种可操作的【吟唱使】角色，各自擅长不同系别法术？
- [ ] 【改良卡】失败的反效果具体是什么（走形为反效果、白费、扣血或其他）？
- [ ] 【建筑合成】与【建筑升级】规则是否进入第一版核心循环？
