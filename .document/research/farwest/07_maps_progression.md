## 1. 地图系统

每张地图有**固定布局**的地形、机制、任务和秘密，但以下要素是**随机生成**的：

- 玩家出生点
- 主要目标位置
- Boss Spawner 位置
- 撤离点
- 各种兴趣点

## 3. 进度与收集系统

### 3.1 等级系统（详见 01_overview）

三类等级并行提升：
- 猎人等级（Hunter Level）
- 装备等级（Equipment Level）
- 法术等级（Spell Level）

### 3.2 转生（Prestige）

- **条件**：猎人或任意武器达到 Lv.100
- **效果**：
  - 等级重置为 1
  - 出售所有升级
  - 已装备 Jokers 移至库存
- **奖励**：获得 Token
  - 解锁额外的 Joker 槽位和升级槽位
  - 或购买资源（金币、灵魂、票券、碎片）

### 3.3 收集品系统

| 收集品 | 用途 | 获取方式 |
|--------|------|----------|
| **Disc Fragments** | 组装唱片改变大厅音乐 | 散布在所有地图中 |
| **Jokers** | Build 核心 | 局内掉落/Slot Machine/购买 |
| **Gold** | 货币 | 局内掉落 |
| **Souls** | Slot Machine 抽 Joker | 局内掉落 |
| **Fragments** | 解锁装备 | 局内追踪后掉落 |

### 3.4 任务线

## 4. 设计启示

### 4.1 固定 + 随机的地图设计

- **固定**：地形、任务线、秘密位置 → 让玩家能学习地图、记住秘密点
- **随机**：出生点、目标点、Boss 点 → 保持每局新鲜感

这种设计兼顾了"可学习性"和"可重玩性"。

### 4.2 地图主题差异化

7 张地图覆盖了多种环境主题：
- 废墟战场（Far West）
- 沙漠（Desert）
- 峡谷（Canyon）
- 雨林（Woodlands）
- 科幻/军事（Area 41）
- 冰雪（Far Far North）
- 丛林神庙（Jungle）

每张地图有独特的秘密和 NPC，鼓励玩家探索全部地图。

### 4.3 进度系统总结

Far Far West 的进度系统是多层次、互相交织的：

```
短期目标（单局）：
  └─ 完成任务目标 → 击败 Boss → 收集 Jokers/金币/灵魂

中期目标（数局）：
  ├─ 追踪并收集碎片解锁新装备
  ├─ 提升装备/法术等级解锁新内容
  └─ 收集 Disc Fragments 解锁音乐

长期目标（数十局）：
  ├─ 将猎人/装备升至 Lv.100
  ├─ 转生获得 Token 扩展槽位
  ├─ 解锁所有武器 Unique Jokers
  └─ 探索所有地图秘密
```

### 4.4 可借鉴的设计

1. **唱片收集改变音乐**：将"收集品"与"玩家体验自定义"结合，比单纯加属性更有成就感
2. **地图专属任务线**：鼓励玩家每张地图都玩多次，而非只刷最喜欢的图
3. **转生系统延长生命周期**：达到满级后不是终点，而是新的开始
4. **秘密命名统一为"XX Secret"**：如 Bell Shot、Cactus Day、Pick Pick，形成品牌化的秘密命名风格
