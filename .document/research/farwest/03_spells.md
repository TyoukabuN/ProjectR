## 1. 法术基础机制

法术是局内可配置的主动技能，每个玩家可装备一套法术组合。法术分为 5 大元素类别，每个类别有 5 个法术，随法术等级逐步解锁。

### 1.1 元素类别定位

| 元素 | 定位 | 特色 |
|------|------|------|
| **Pyro（火焰）** | 纯伤害输出 | 高爆发、持续燃烧 |
| **Elec（雷电）** | 机动 + 爆发 | 位移、高伤、状态传导 |
| **Acid（酸液）** | 控场 + 持续伤害 | 减速、大范围 DOT |
| **Voodoo（巫毒）** | 辅助 + 控制 | 治疗、复活、策反敌人 |
| **Cactus（仙人掌）** | 召唤物体系 | 自动战斗单位、地形控制 |

### 1.2 元素状态效果

Pyro、Elec、Acid 三类元素可对敌人施加状态效果：

| 元素 | 状态效果 |
|------|----------|
| **Pyro** | 每秒造成 2 点伤害（双倍于其他元素） |
| **Elec** | 每秒造成 1 点伤害，可在敌人之间传导扩散 |
| **Acid** | 每秒造成 1 点伤害，敌人移动速度 -30% |

此外，部分武器和法术可在地面留下**元素水坑（Elemental Puddles）**，踩踏的敌人会获得对应元素状态。Acid 水坑与其他元素水坑接触时会产生**爆炸**，并将自身转化为接触元素的类型。

## 3. 法术组合系统（Spell Combinations）

法术组合是 Far Far West 的核心交互机制，鼓励团队配合和创造性 Build：

### 3.1 元素 + 元素组合

| 组合 | 效果 |
|------|------|
| Firebeam + Acid 水坑（或反向） | 召唤火焰龙卷风，大范围高伤害 |
| Pyro 水坑 + Bubble | 召唤火焰龙卷风 |
| Elec 状态 + Wisp | Wisp 在目标间快速跳跃 |
| Elec 状态 + Geyser | 额外召唤 3 个 Geyser |

### 3.2 元素 + Cactus 召唤物组合

| 组合 | 效果 |
|------|------|
| Strikes + 任意 Cactus 召唤物 | 从召唤物向 8 个方向发射闪电 |
| 任意非 Cactus 法术 + Mino | Mino 继承该元素属性进行一次爆炸 |
| 任意法术 + Portal | 法术投射物穿过 Portal 时被复制 |

### 3.3 元素注入（Infusion）

Cactus 召唤物可被 Pyro / Elec / Acid 注入元素：

| 召唤物 | Pyro 注入 | Elec 注入 | Acid 注入 |
|--------|-----------|-----------|-----------|
| Mino | 爆炸附加元素伤害和传播状态 | 爆炸附加元素伤害和传播状态 | 爆炸附加元素伤害和传播状态 |
| Pistolero | 射击附加元素伤害 | 射击附加元素伤害 | 射击附加元素伤害 |
| Wallo | 附加元素伤害和状态 | 附加元素伤害和状态 | 附加元素伤害和状态 |
| Bandito | 攻击附加强力 DOT | 移速增加 | 移动留下酸液水坑痕迹 |

### 3.4 Voodoo + Cactus 组合

| 组合 | 效果 |
|------|------|
| Drain/Rescue/Corruption/Ritual/Doll 靠近 Cactus Mino | 腐化 Mino，下次爆炸策反敌人使其为玩家战斗 |
| Ritual 靠近任意 Cactus 召唤物 | 召唤物也辐射 Ritual 光环 |
| Ritual 在 Pistolero/Decoyo 20 米内 | 召唤物传播 Ritual 效果，治疗圈重叠可叠加治疗 |

## 4. 设计启示

1. **法术分级解锁提供长期目标**：每个元素 5 个法术分 5 个等级阶段解锁，给玩家持续的升级动力
2. **元素组合创造"化学引擎"**：不同元素法术和召唤物之间的交互反应，提供了远超单法术总和的策略深度
3. **Portal 作为"法术倍增器"**：5 秒冷却的 Portal 可以复制任何投射物法术，是团队配合的核心技能
4. **Voodoo 填补了辅助定位**：在主打伤害的射击游戏中，Voodoo 提供了治疗、复活、策反等独特功能，丰富了团队角色分工
5. **Cactus 召唤物 + 元素注入 = 自动 Build**：玩家可以构建"召唤物流"，让召唤物自动战斗并附加元素效果，降低操作门槛的同时保持策略性
6. **冷却时间差异化设计**：低阶法术 5-30 秒高频使用，高阶法术 95-135 秒作为"大招"，形成清晰的技能使用节奏
