# 游戏概览与核心机制

[返回索引](00_index.md) · [下一章 >>](02_cards_characters.md)

## 游戏定位

- **类型**：休闲回合制卡组构建 + Roguelite
- **平台**：Xbox Series S|X / Steam / PlayStation 5 / Nintendo Switch
- **发售**：2026年4月21日
- **开发商**：poncle（Vampire Survivors 同一开发商）
- **定位**：VS 宇宙的首款衍生作品，将自动射击改为卡牌出牌

## 核心玩法循环

```
进入地牢 → 探索楼层 → 出牌战斗 → 获取宝箱/升级 → 构建卡组 → Boss战 → 解锁新内容
```

- 每个地牢分为多个楼层（Floor），目标是找到铲子挖到下一层
- 回合制出牌，按法力费用支付打出卡牌
- 击败敌人获得经验升级，升级时选择新卡牌或宝石
- 宝箱中可获得宝石、卡牌、Evolution宝石

## 核心机制详解

### 1. TurboTurn 连击系统（核心战斗机制）

TurboTurn 是 poncle 对本作核心战斗机制的命名，本质是 **Mana Chain 升序出牌倍率系统**。

**Mana Chain 倍率表：**

| 出牌费用 | 对下一张牌的倍率 |
|---|---|
| 0费卡 | 下一张 ×2 |
| 1费卡 | 下一张 ×3 |
| 2费卡 | 下一张 ×4 |
| 3费卡 | 下一张 ×5 |

**完整链条：0费 → 1费 → 2费 → 3费 = ×120 总倍率！**

例如：Spellbinder(0费) → Knife(1费) → Fire Wand(2费) → Holy Wand(3费)，最终 Holy Wand 的伤害为原伤害×120。

**关键规则：**
- 相同费用卡牌不会打断Combo，但**也不会推进链条**（倍率停滞）
- Wild卡(W费用)可插入任意位置，不打破升序，但自身不贡献倍率，使用后销毁
- 大部分伤害输出来自Combo倍率而非卡牌本身——**弱卡打对位置 > 强卡打错位置**
- Combo Stack 遗物解锁此机制（教程中获得）
- Chain Link 秘法可使 Combo 跨回合保持
- Reverse Combo 宝石允许向下递减延续Combo
- Easy Combo 宝石允许任意费用衔接

### 2. Mana 法力系统

- 每回合有法力上限，出牌消耗法力
- 法力卡（紫色）用于回复法力
- 部分卡牌有法力回复效果（如 Arca 角色）
- Sharp Mind 秘法允许保留最多5点法力跨回合
- Mana Syphon 秘法每100张牌永久+1法力

### 3. Crawler 角色触发系统

- 角色卡打出后进入场上的 Crawler 位
- 每个角色有**触发条件**（某颜色卡牌被打出时触发）
- 触发效果持续由 **Duration** 属性决定次数
- Duration 越高，Crawler 触发次数越多
- Over The Top 秘法使 Crawler 离场后回到牌堆顶

### 4. 宝石镶嵌系统

- Gem Hammer 遗物解锁宝石镶嵌
- 卡牌有空宝石槽可镶嵌宝石
- 同种宝石可叠加（效果翻倍）
- 宝石来源：升级选择 / 宝箱
- 稀有度：Common → Uncommon → Rare → Very Rare → Ultra Rare

### 5. 进化系统

- 特定卡牌组合 + Evolution 宝石 = 进化为更强武器
- 主卡需有空宝石槽插入 Evolution 宝石
- 进化后主卡上的宝石保留，副卡的宝石丢失
- Peachone + Ebony Wings 可直接 Union（无需Evolution宝石）

### 6. 手牌与牌组

- **Deck**（牌堆）：所有卡牌
- **Hand**（手牌）：当前回合可出的牌
- **Discard**（弃牌堆）：已出的牌
- Hand 大小由 Hand 属性决定
- Draw 效果从牌堆抽牌到手牌

## 回合与遭遇战流程（TurboTurn）

### 地牢楼层结构

```
地牢 → 多个楼层(Floor) → 每层有多个遭遇战(Encounter) → 每个遭遇战有多个回合(Turn)
```

- 每层目标是找到铲子挖到下一层
- 遭遇战 = 与一组敌人的单场战斗
- 回合 = 一次出牌循环（抽牌→出牌→结束回合）

### 单个回合流程

```
┌──────────────────────────────────────────────────────┐
│  1. 回合开始                                          │
│     ├─ 抽 Hand 数值的卡到手牌（从牌堆抽取）             │
│     ├─ Crawler 触发能力激活（Make a Scene 秘法时免费触发）│
│     └─ Quick Draw 宝石卡优先抽出                       │
│                                                       │
│  2. 出牌阶段                                          │
│     ├─ 按法力费用升序打出卡牌，构建 TurboTurn 链         │
│     ├─ Mana Chain: 0费→×2, 1费→×3, 2费→×4, 3费→×5     │
│     ├─ Wild卡(W费用)可插入任意位置不断链（使用后销毁）    │
│     ├─ 相同费用卡不会断链但也不推进倍率                  │
│     └─ 可随时按下“结束回合”按钮                         │
│                                                       │
│  3. 结束回合                                          │
│     ├─ 未用法力 → 清零（Sharp Mind 秘法可保留5点）       │
│     ├─ 手牌中未打出卡 → 全部进入弃牌堆（Retain 宝石卡除外）│
│     ├─ 已打出卡 → 进入弃牌堆（Return 宝石卡返回手牌）     │
│     ├─ Combo 倍率 → 重置（Chain Link 秘法除外）          │
│     ├─ 护甲 → 清零（Your Shield My Liege 秘法除外）     │
│     ├─ 碎裂(Cracked)卡 → 自动修复                      │
│     └─ 牌堆耗尽时 → 弃牌堆洗入牌堆                      │
│                                                       │
│  4. 敌人行动                                          │
│     ├─ 敌人对你造成伤害                                 │
│     ├─ Boss 的“眼睛”机制：每打出一张卡或结束回合，       │
│     │  一只眼睛亮起。全部亮起后Boss释放大招（333+伤害）    │
│     └─ 冻结(Freeze)可跳过敌人攻击                       │
│                                                       │
│  5. 判断遭遇战是否结束                                  │
│     ├─ 敌人全灭 → 遭遇战结束，Recovery 属性治疗         │
│     └─ 敌人存活 → 回到步骤1，开始新回合                  │
└──────────────────────────────────────────────────────┘
```

### 回合间重置表

| 重置项 | 默认行为 | 例外/保留手段 |
|---|---|---|
| 手牌 | 重新抽取 | Retain 宝石卡保留在手牌 |
| 法力 | 清零 | Sharp Mind 秘法保留5点 |
| Combo 倍率 | 重置 | Chain Link 秘法保持 |
| 护甲 | 清零 | Your Shield My Liege 秘法保持 |
| 碎裂卡 | 自动修复 | - |

### 关键策略要点

1. **提前结束回合是高级操作**：如果手牌无法构建好的Combo链，不如提前结束回合等待下次抽牌
2. **可破坏(Breakable)卡与Combo倍率**：永久属性加成卡也受Combo倍率影响！在链尾打出可获得巨额永久加成（如Combo×50时打出Heart卡可获40+永久生命）
3. **精简牌组 = 稳定输出**：小牌组循环更快，12张精简牌组每回合都能稳定打出0→1→2→3完整链
4. **Wild卡是稀缺资源**：使用后销毁，留到Boss战或关键Combo链使用
5. **Boss眼睛计时器**：需要平衡“打出更多卡积累Combo”与“在Boss大招前叠甲/冻结”的矛盾
6. **牌堆耗尽自动洗牌**：弃牌堆重新洗入成为新牌堆，标准 deckbuilder 循环

## 设计启示

1. **VS IP 衍生思路**：将自动射击的“武器组合”变为“卡牌组合”，保留进化/Union的爽感但改变表达形式
2. **TurboTurn = 序列即伤害**：不是“哪张牌强”而是“哪张牌在哪个位置”，出牌顺序决定一切——这是与StS最大的区别
3. **×120倍率的恐怖曲线**：从×2到×120的指数增长意味着后期一回合清场，对数值膨胀极度宽容
4. **Crawler触发系统**：角色不是被动属性，而是有条件触发的主动效果，类似“条件型被动技能”
5. **宝石=附魔**：给卡牌添加可定制的效果，增加构建深度，类似 Slay the Spire 的遗物但更灵活
6. **双资源管理**：Mana（回合资源）+ Combo（序列资源），两种资源的交织产生策略深度
7. **相同费用不推进但不断链**：这个设计允许玩家“填充”回合而不浪费，降低操作压力
8. **Wiki不写机制**：官方Wiki只做数据参考，机制说明依赖第三方攻略站——说明数据与教程分离的设计文档思路
