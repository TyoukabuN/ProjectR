## 1. 目标系统概述

每个任务包含一个**主要目标（Main Objective）**，完成后获得摧毁**Boss Spawner**的能力，从而召唤并击败**悬赏 Boss（Bounty Boss）**以完成任务。

主要目标的设计多样，涵盖解谜、护送、保护、制造等多种玩法机制，避免重复的"杀光所有敌人"体验。

---

## 2. 七大主要目标

### 2.1 Craft an Overloaded TNT（制造超载炸药）

**玩法流程**：
1. 找到 TNT 工厂并启动
2. 制造过程中工厂会定期故障，需要修复
3. 制造完成后射击工厂的螺旋桨完成炸药制作
4. 使用炸药摧毁 Boss Spawner

**设计要点**：
- 需要保护/维护制造设施
- 有明确的"阶段性目标"（启动 → 维护 → 完成）

### 2.2 Destroy a Cryptic Totem（摧毁神秘图腾）

**玩法流程**：
1. 对仪式图腾进行充能引导，召唤无限风暴
2. 在风暴中击杀指定数量的敌人
3. 摧毁图腾，期间图腾会释放伤害性冲击波
4. 图腾释放 Cryptic Key，用于解锁 Boss Spawner

**设计要点**：
- 分两阶段：生存阶段（杀怪）+ 摧毁阶段（躲避冲击波）
- 环境危险（无限风暴）+ 机制危险（冲击波）叠加

### 2.3 Launch a Nuclear Missile（发射核导弹）

**玩法流程**：
1. 打开核弹头前端
2. 将炸药塞入核弹头
3. 四人（或机制互动）同时触发四个发射杆
4. 发射序列就绪后发射导弹摧毁 Boss Spawner

**设计要点**：
- 多人协作机制（需要同时触发多个开关）
- 有明确的"准备 → 执行"节奏

### 2.4 Protect a Drill Machine（保护钻机）

**玩法流程**：
1. 激活钻机
2. 钻机进入充电期，期间需要管理压力水平
3. 充电完成后钻机钻向 Boss Spawner
4. 按下大红按钮让钻机摧毁 Boss Spawner

**设计要点**：
- 典型的"护送/保护"变体
- 资源管理元素（压力水平）

### 2.5 Escort a Payload（护送爆炸载荷）

**玩法流程**：
1. 解锁被多个安全开关守护的爆炸载荷
2. 按正确顺序扳动安全开关
3. 护送载荷到达 Boss Spawner
4. 引爆载荷摧毁 Boss Spawner

**设计要点**：
- 解谜元素（正确顺序扳动开关）
- 护送 + 解谜的复合玩法

### 2.6 Fire a Nitro Cannon（发射硝化甘油大炮）

**状态**：Wiki 中描述缺失（Description.）

**推测**：可能是类似"装填 → 瞄准 → 发射"的炮兵机制

### 2.7 Craft a Gas Bomb（制造毒气炸弹）

**玩法流程**：
1. 启动投影仪显示所需物品
2. 记忆并收集所需物品
3. 制造过程中需要额外物品
4. 将毒气炸弹安置在 Boss Spawner 上并射击引爆

**设计要点**：
- 记忆 + 收集的复合机制
- 阶段性需求变化（中途需要额外物品）

## 4. 设计启示

### 4.1 目标设计多样性

7 种主要目标涵盖了多种玩法原型：

| 目标 | 核心玩法 | 协作要求 |
|------|----------|----------|
| 超载炸药 | 设施维护 | 低 |
| 摧毁图腾 | 生存 + 摧毁 | 中 |
| 核导弹 | 协作触发 | 高 |
| 保护钻机 | 资源管理 | 中 |
| 护送载荷 | 解谜 + 护送 | 中 |
| 硝化大炮 | （推测）炮兵 | 低 |
| 毒气炸弹 | 记忆 + 收集 | 低 |

### 4.2 值得借鉴的设计

1. **完成目标 → 解锁 Boss 的两段式结构**：避免玩家一开始就直接打 Boss，强制体验完整的任务流程
2. **目标即"钥匙"机制**：完成任务后获得"摧毁/解锁 Boss Spawner"的能力，逻辑自洽
3. **多人协作嵌入目标设计**：核导弹需要多人同时触发开关，天然鼓励团队合作
4. **阶段性流程**：大部分目标都有"准备 → 执行 → 完成"的三段式节奏，避免单调
5. **环境压力与目标并行**：图腾的风暴、钻机的压力管理等，让玩家在"做目标"的同时还要"应对环境"

### 4.3 潜在改进空间

1. **次要目标缺失**：目前次要目标内容为空，可以考虑增加如"限时挑战"、"无伤完成"等次要目标增加重玩价值
2. **目标与地图的结合**：不同目标在不同地图上的表现可以进一步差异化（如护送载荷在沙漠 vs 雪原的体验差异）
